I build small, focused tools for people who don't think of themselves as technical. No jargon, no config screens, no manuals required. Where it makes sense, I build local-first - your data stays on your machine.

## Currently building

- **[CopySprout](https://copysprout.app)** - AI writing for Etsy sellers. Sixteen tools for the everyday parts of running a shop, written in plain language.
- **[Handmade Checker](https://handmadechecker.com)** - free Chrome extension that spots AI-generated and dropshipped listings on Etsy.
- **[IndieGameScout](https://tarlow.itch.io/indiegamescout-itchio-stats-tracker)** - desktop app that tracks itch.io stats over time: ratings, jam ranks, views, downloads, earnings.

## Writing
